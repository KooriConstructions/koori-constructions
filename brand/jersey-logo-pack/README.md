# Koori Constructions — Sponsor Logo Pack (Rugby League Jerseys)

Hand this whole folder to the club / jersey manufacturer. It contains every
format they should need for sublimated jerseys, plus one-colour versions for
embroidery, screen printing, training polos, caps and socks.

## Files

| File | Use it when |
|---|---|
| `KC_logo_full-colour_transparent.svg` | **Preferred file for the manufacturer.** Vector, scales to any size, transparent background, white keyline included. |
| `KC_logo_full-colour_transparent.png` | Same artwork as high-res PNG (3705 × 2590 px) if their design software can't take SVG. |
| `KC_logo_full-colour_no-keyline_for-light-jerseys.png` | Full colour with the white outline removed — for white or very light jerseys where the keyline serves no purpose. |
| `KC_logo_one-colour_white.svg` / `.png` | Single-colour white "knockout" version — jersey colour shows through the flag, rooflines and lettering. For dark jerseys when only one print colour is available (embroidery, heat press, socks, caps). |
| `KC_logo_one-colour_black.svg` / `.png` | Same knockout artwork in black, for light or gold garments. |
| `preview_jersey-colours.png` | Mockups of each variant on navy, maroon, white and gold so the club can pick at a glance. |

## Versions with the Aboriginal artwork (shaped, not rectangular)

| File | What it is |
|---|---|
| `KC_logo_art-roof.png` | The standard logo with the artwork filling the roof instead of flat black (darkened so the flag and rooflines still read). Same badge silhouette as the plain logo. |
| `KC_logo_art-badge.png` | The artwork cropped to the house-badge silhouette, sitting behind the logo as a border, with a white keyline. |
| `KC_logo_art-roundel.png` | Circular crop of the artwork with a white ring and the logo centred — classic sponsor-patch shape. |
| `preview_art-shapes.png` | All three on navy, maroon and white. |

These are raster-only (the dot artwork can't be vectorised meaningfully) —
that's fine for sublimated jerseys, which print them like a photo. **Use them
at front-centre or back-panel sizes (200 mm+).** At left-chest size the dot
art turns to visual noise — use the plain logo there instead. They cannot be
embroidered; embroidery gets the plain or one-colour logo only.

## Which version on which jersey

- **Dark jerseys (navy, black, dark green):** full-colour with keyline — the
  white outline is what keeps the black roof visible against a dark strip.
- **Mid-tone jerseys (maroon, red, royal):** full-colour with keyline.
- **White / light jerseys:** full-colour no-keyline version.
- **One print colour only:** the white or black knockout version, whichever
  contrasts with the garment.

## Brand colours

| Colour | HEX | RGB | CMYK (approx.) |
|---|---|---|---|
| KC Blue | `#00B2FF` | 0 / 178 / 255 | 100 / 30 / 0 / 0 |
| Black | `#000000` | 0 / 0 / 0 | 0 / 0 / 0 / 100 |
| White (keyline) | `#FFFFFF` | 255 / 255 / 255 | — |

Jerseys are almost always dye-sublimated, so full colour costs nothing extra —
give the printer the HEX values above. If they insist on Pantone, ask them to
match `#00B2FF` on their swatch book (closest coated references are in the
PMS 2995 C / 306 C region) and approve a strike-off before the run.

## Sizing guidance (standard sponsor placements)

- **Front centre chest:** 200–250 mm wide
- **Back, above or below numbers:** 250–300 mm wide
- **Left chest / sleeve / shorts:** 80–100 mm wide
- **Minimum size:** don't go below ~60 mm wide — the Aboriginal flag detail
  and rooflines become too fine to read.

The white keyline should never be deleted on dark strips and no one should
recolour, stretch, rotate or add effects to the logo — send this pack rather
than a screenshot so that doesn't happen.

## Fine detail warning (embroidery only)

The flag outline and roofline strokes are thin. Sublimation and quality screen
printing handle them fine at the sizes above, but for **embroidery** at left-
chest size the embroiderer may need to thicken or simplify the flag lines —
ask for a stitch-out sample before approving.
